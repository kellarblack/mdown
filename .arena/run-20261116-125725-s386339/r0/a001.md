# The hero lockup: one em drives it

Two edits, in the two files you have open. Nothing else on the page is restyled.

## 1. `index.html` — replace the whole `<h1 class="hero-logo"> … </h1>` block

```html
    <h1 class="hero-logo">
      <span class="hero-mark" aria-hidden="true"><svg viewBox="0 0 20 20" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
        <!-- two groups, one gesture: the arrow falls into the tray, and the
             second half of the name falls with it, the same distance, on the
             same curve -->
        <g class="mark-arrow"><path d="M10 3.5V11.4"/><path d="m6.4 7.8 3.6 3.6 3.6-3.6"/></g>
        <path d="M3.5 11.4v3.6a1.4 1.4 0 0 0 1.4 1.4h10.2a1.4 1.4 0 0 0 1.4-1.4v-3.6"/>
      </svg></span><span class="hero-word"><span class="hero-word-m">m</span><span class="hero-word-down">down</span><span class="hero-word-tld">.cc</span></span><span class="sr-only"> — a media downloader for video and audio</span>
    </h1>
```

Paste it as one piece, with no line break inside `.hero-word`. A break would not change the layout (the row is a flex container), but it would end up in what a visitor copies when they select the name.

## 2. `assets/app.css` — replace the hero block

Delete from the comment `/* one flow: the arrow rises … */` down to and including `.hero-logo { margin-bottom: clamp(18px, 3vh, 28px); }` (around line 2300), and paste this in its place:

```css
/* One object, not two things parked beside each other. The lockup has one unit
   of size — the em of this block. The mark is a square that size, the gap is a
   fifth of it, the drop is a little less again, so the three hold their ratio
   from 320px to 1440px instead of drifting apart the way two separate clamps
   with a fixed pixel gap do. */
.hero-logo {
  display: flex; align-items: center; justify-content: center; gap: 0.2em;
  margin: 0 auto clamp(18px, 3vh, 28px);
  color: var(--text);
  font-size: clamp(1.85rem, 0.9rem + 2.2vw, 2.5rem);   /* 29.6px … 40px */
  line-height: 1;
}

/* The box is a square and the drawing is inset only enough to hold its stroke,
   so the row centres ink rather than padding. Stroke is 1.5 of 20 = 0.075em,
   the icon system's own ratio (1.7 of 24): 3px at 40px, sitting under the
   wordmark's 3–4px stems. A hair under the name, never over it. */
.hero-mark {
  flex: none; width: 1em; height: 1em;
  color: var(--text);
  /* the tray is a solid horizontal and a solid horizontal reads low: lift the
     whole mark about a pixel so the eye puts it level with the word */
  transform: translateY(-0.03em);
}
.hero-mark svg { display: block; width: 100%; height: 100%; }

/* The wordmark. Mono already has a rhythm, so the name is not re-spaced here:
   the old block tracked it to -0.03em and kept a permanent 0.05em margin
   between the m and "down" — a break in the grid that never came off. */
.hero-word {
  display: flex; align-items: baseline; letter-spacing: 0; white-space: nowrap;
  font-family: var(--mono); font-weight: 500;
}

/* The suffix steps down once in size (0.84em) and once in ink (--text-2), and
   the period goes with it: at that size SF Mono's square period reads as a
   period rather than a 7px bullet, and .cc is punctuation for the domain, not a
   full stop after the name. The -0.05em is the only tracking in the lockup —
   a mono cell leaves 14px of air around a full-size period at 40px, and closing
   it puts an even 10.5px on both sides. The weight stays 500: three separate
   de-emphases are what made the old tld look like a footnote. */
.hero-word-tld { font-size: 0.84em; letter-spacing: -0.05em; color: var(--text-2); }

/* One gesture in two parts: the arrow falls into the tray while "down" falls
   with it — the same distance, on the switch's curve, 760ms, once. No stagger
   (a stagger is what made the old entrance read as two events), no fade, no
   bounce. Transform only, so nothing re-lays-out and nothing leaves the box. */
.hero-word-down, .mark-arrow { animation: hero-drop 760ms var(--ease) both; }
.hero-word-down { --drop: -0.13em; }  /* em of the wordmark */
.mark-arrow     { --drop: -2.6px; }   /* svg units: 2.6 of 20 is the same 0.13em */
@keyframes hero-drop {
  from { transform: translateY(var(--drop, 0)); }
  to   { transform: translateY(0); }
}
/* nobody asked for motion: show the lockup and be done */
@media (prefers-reduced-motion: reduce) {
  .hero-word-down, .mark-arrow { animation: none; }
}
```

That block replaces `.hero-logo` (declared three times, `margin-bottom` twice), `.hero-mark`, `.hero-mark svg`, `.mark-arrow`, `.hero-word`, `.hero-type`, `.hero-word-m`, `.hero-word-down` (twice), `.hero-word-dot`, `.hero-word-sub`, and the keyframes `hero-fade-in`, `arrow-drop`, `word-drop` plus their reduced-motion rule. New selector: `.hero-word-tld`. `.hero { width: 100% }` above and the landscape rule further down (`.hero-logo { display: none }`) are untouched, so the mark still disappears on a phone on its side. If the old CSS lingers after you reload, bump `?v=` on the `app.css` link in `index.html` — the browser is holding a cached copy, not ignoring your edit.

## Why this, not the old one

The old lockup was two objects side by side, sized by two independent clamps and a fixed 14px gap, so the air between them was 0.57em on a desktop and 0.71em on a phone — 25% looser where the page is tightest. The `.` was set in `--accent`, the same value as `--text`, while `.cc` sat in the faintest grey: the period was painted at full strength while the suffix it punctuates almost disappeared. And `m` kept a permanent 0.05em margin, so the name never sat on its grid.

Now one em drives the mark, the gap and the fall — 0.40em of air at 320px and at 1440px. The tray's ends turn up, so the arrow falls into something. The suffix takes one size step and one ink step, and the period goes with it. Both parts fall 5.2px, together.

## What I checked

Measured in Chrome off 2× screenshots of the patched page, not by eye:

- 500 / 900 / 1440px: the wordmark measures 4.402em at all three, the mark is exactly 1em and the gap a fifth of it — the lockup's proportions do not move with the viewport.
- 1440px: mark ink 28.5px tall, top 1.5px under the `d`'s ascender, bottom 1px above the baseline; the lockup's box is centred to the pixel on a 1440 viewport.
- Stroke 3.0px, with the wordmark's stems at 3–4px, scanned off the screenshot.
- Frame 0, paused: arrow and `down` both exactly 5.2px high; mid-fall, both 1.5px. The tray does not move and the `.`/`.cc` boxes are identical in every frame, so nothing reflows.
- 320 / 360 / 390 / 1440px: one line, centred, `scrollWidth == clientWidth`; 740×390 landscape still hides it; `prefers-reduced-motion: reduce` shows the finished state; light theme holds the two-step ink.
- `<h1>` text is still `mdown.cc — a media downloader for video and audio`; mark still `aria-hidden`; no JS, no images, no new tokens.
- One consequence, in the open: the hero box is 4px shorter at desktop (the old one was 44px tall because the mark's box outgrew the word), so on a centred column the lockup sits 2px lower and the composer 2px higher. Nothing else moved.

## Three knobs

- **Size:** the `font-size` clamp only. Mark, gap and fall all follow it.
- **Air:** `gap: 0.2em` on `.hero-logo`. 0.16 is tighter, 0.26 is airier.
- **Fall:** the two `--drop` values must stay equal. `-0.13em` is `-2.6px` of a 20-unit grid (0.13 × 20); move both or neither.

## Assumptions

- "Monochrome, existing custom properties" means no new tokens. `--accent` is the same value as `--text` in both themes, which is why the old dot rule painted the period at full strength; the hierarchy is now `--text` for the name, `--text-2` for the domain.
- The arrow-into-tray mark stays — the task names it. Only its drawing, proportion, weight and alignment change.
- No tagline, no spotlight, no per-letter choreography: the `.sr-only` sentence is left exactly as it was, so the accessible name is unchanged.

## Verify at a glance

**1440px** — the mark's top should sit level with the `d`'s ascender and its tray just above the baseline, with no air pocket before the `m`; the period should read as punctuation, spaced evenly between `n` and `cc`. Reload once: the arrow and `down` land together, dead level.
**360px** — the same three distances, all scaled by the same factor, on one line and nothing clipped at the edge. With Reduce Motion on, the lockup is simply there.
