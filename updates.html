Updates

1.3 14 nov 2026 latest

Phones, properly

  • A download now shows itself: the queue opens on any screen, the bar fills with real percentages, speed and time left, and the badge pulses while work is running. It used to open only above 720px, so phones saw nothing until the file arrived.
  • Paste tells you what to do when the clipboard is blocked on iOS or Android, instead of naming a Mac shortcut.
  • iOS hands downloads to Safari's downloader — a blob opens in a viewer there and never reaches Files.
  • fetch is a full-width 48px target on phones, and the modes split the row evenly.
  • Fields are 16px on phones so iOS stops zooming the page when you tap them.
  • No accidental pull-to-refresh mid-download. No sideways scroll at 320px.
  • The status pill says online instead of a hostname, with the address in its tooltip.
  • The hero no longer labels the page — it says what to do: paste a link, get a file.
  • A test taps every visible button on a 390px screen and fails if any of them throws.
  • A donate page that states what the site costs to run instead of asking vaguely, with card, recurring and plain-address options, and nothing at all loaded from a third party.
  • An updates page (this one), a grid for supported services, and a one-line explanation at the top of every settings pane. "Output" is now "Files", because that's what it holds.
  • The active nav item stopped looking like a button — it names where you are now.
  • Sharing moved onto the donate page: copy the link, or post it straight to x, threads, reddit or bluesky. Each one is an ordinary link with no referrer, so nothing is requested until you press it.
1.2 13 nov 2026

It's live

  • mdown.cc served statically with a real certificate and HTTPS enforced; api.mdown.cc on the box, Let's Encrypt, renewing itself.
  • 8 parallel range requests per download instead of 4 — measured 39% faster on a 900 MB 4K file. 16 was slower on one core.
  • Output cap raised to 2 GB. The old 800 MB ceiling rejected a 966 MB 4K file, which meant the highest quality was advertised and then refused.
  • Range requests: a dropped connection on a big file resumes instead of starting over.
  • Files over 200 MB go straight to the browser. Buffering a gigabyte in the JS heap killed the tab.
  • A watchdog restarts the API when it's alive but wedged; a scheduled check opens an issue if the box stops answering.
  • A refused POST no longer poisons the connection — that showed up as "can't reach the API" on the second attempt.
1.1 12 nov 2026

Limits that tell the truth

  • Error messages name the actual problem: daily cap, burst limit, full queue, disk space, a missing API key.
  • The status page reports real uptime from the API's own checks.
  • A content security policy on every page, verified to allow the local ffmpeg engine and nothing else.
  • Donations dialog, off by default, that loads nothing from anywhere.
1.0 11 nov 2026

First release

  • One page: paste a link, pick a mode, get a file. No account, no build step.
  • Its own API: yt-dlp + ffmpeg, no Docker, no Node, caps on duration, height and size.
  • Remux, subtitle extraction and metadata cleaning run locally in your browser — those files never leave your device.
  • Pickers for playlists, subtitle embedding, silent video, and untouched source audio.

The code is open source under the MIT licence. Back to the downloader.
