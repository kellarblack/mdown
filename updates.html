1.3 14 nov 2026 latest

Phones, properly

  • auto reads the link: a music service gets audio, everything else gets video. audio and video force it, and no sound is a switch rather than a fourth button nobody understood.
  • Paste a link and the field shows the size, the running time, the resolution and a thumbnail before anything is fetched. The queue keeps the picture.
  • On a phone there is a bottom bar now — downloads, remux, settings, updates — within thumb reach, with the queue opening as a sheet above it. The top bar keeps only the name and the green dot.
  • A file over 250 MB now asks first: the estimated size, how much data it will use, and a cancel button. Small files start straight away.
  • Downloads move through the socket with zero-copy sendfile and 256 KB writes instead of 64 KB, so the box spends less time copying and more time sending.
  • The sources panel says what it is: listed for technical compatibility only, with no affiliation, endorsement or partnership. The same sentence is in the terms.
  • On a phone the sources trigger sits under the field, so its panel opens over the hint and the tools — never across the wordmark.
  • The sources list is one small panel: all 33, even columns, measured against the wordmark so it never touches it, denser on a phone.
  • The field is simply there on load. The arrow drops into the tray, the name types itself once, and the green dot breathes without a glow.
  • A link that won't go gets a short shake and a red outline. Notices cap at three, and hammering fetch can't bury the page or clear what you typed.
  • Settings open with the two choices you actually make; codec, dubbing, subtitles and the API key sit behind a +. Server is one field, one card, one Check.
  • The three browser tools are under the field — remux, subtitles, metadata — instead of inside a menu nobody opened.
  • The file preview in Settings is the file: name, container, quality, and whether it has sound.
  • Mobile: 16px fields, a full-width fetch, no double-tap zoom, no pull-to-refresh, and a saved-file message that names Files → Downloads or Downloads.
  • There is no ad slot in the code, and there never will be. The privacy check now fails the build if advertising markup appears. Donations or nothing.
  • Link previews got a 1200×630 card for Discord, X, Reddit, iMessage and Android. The footer is real buttons, and the changelog is linked from the page it describes.

The code is open source — fork it, run it yourself. Back to the downloader.
