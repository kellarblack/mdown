1.3 14 nov 2026 latest

Phones, properly

  • The file preview in Settings is the file now: a row with the icon, the exact name, the container, the quality and a video/audio/silent tag, and it follows whichever mode is selected.
  • The front page finally says the other tools exist: three lines for remux, subtitles and metadata, each a real link with one sentence about what it does.
  • The logo is a tile now, and the name types itself once on arrival — eight steps, a 2px caret, then the caret leaves and the "down" settles. Nothing moves after that.
  • The fetch arrow's slot is always visible; only the arrow arrives when a link does, so the footer never changes shape.
  • For the crawlers and the answer engines: a plain-text summary for anyone without JavaScript, the three tools in structured data, a link to llms.txt, and the changelog plus the MIT licence in the footer.
  • The terms now say what the API is: one server, sized for this page, origin-checked and rate-limited, not for other clients or resale. Run your own if you need one.
  • The sources panel got smaller and stopped leaning on the wordmark: 540 wide, six even columns, a taller-than-it-looks scroll area, and the height is measured against the logo when it opens so it always clears it. Chips answer to the pointer.
  • No glow left anywhere. The green dot breathes instead of throwing a ring, status dots are flat, and focus is a crisp 1px line rather than a halo.
  • The page opens as one gesture: the mark and wordmark drop and settle, the field rises under them, and the arrow is the last thing to arrive — and it drops in again each time a link comes back.
  • Spamming the fetch key can no longer bury the page. The same message twice is one message, three is the ceiling, and a link that isn't a link shakes the field once instead of filing a complaint for every tap.
  • Link previews got a proper card: a 1200×630 image with the wordmark and paste a link. keep the file., three claims and no fine print, large-format cards on X, and the same image on Discord, Reddit, iMessage and Android. Every page has its own title, description and alt text.
  • The name on the tin is now mdown.cc — paste a link, keep the file instead of a generic "media downloader", and the queue uses the same words as the buttons: video, audio, silent.
  • The down in the wordmark falls the last few pixels and settles once when the page opens — the same gesture as the mark, and only that half of the name.
  • The composer no longer lights up with a halo when the page loads. Focus is a hairline that gets a shade brighter, nothing more; the glow is gone from the site entirely.
  • The green dot opens a miniature of the status page: online, how long the server has been up, a bar per recent check, the uptime percentage, and two links. It fills in as you use the site — every connection check is a sample — so it is a real graph, not a placeholder.
  • The help and settings copy got shorter again: three steps, six questions, one line of explanation per control, and the rest is folded away. "Connection" is now "Server" everywhere.
  • Settings stopped explaining itself. Video and Audio open with the two choices people actually make — what to download, and how big — and the codec, container, dubbing and TikTok switches sit behind a +. Files, Privacy and Advanced got the same treatment: plain labels, one line of help, everything rare folded away.
  • Connection is now Server: one field, one card that says connected with the host, the service count and how long it has been up, and the API key and the service list behind disclosures. No more paragraph explaining what an API is.
  • The connection pill is a green dot with a soft pulse you can click, not a word in a box. Red when the server is down, amber while checking, and the host moved into its tooltip.
  • There is no fetch button on a desktop any more — the arrow only exists once the field holds a link, and a rejected link answers with one short shake, not a notification. The service mark pops in when a link is recognised. On a phone the full-width target stays, because a thumb needs one.
  • The download bar is a 3px hairline that glides on the compositor instead of a block that jumps, and a waiting job counts its own seconds so it never looks stuck.
  • A dropdown now leaves as cleanly as it arrives: tools, downloads and sources all play a 4px, 120ms exit before they disappear, instead of vanishing under the pointer.
  • Paste a link and the field now tells you what you are about to get: a size estimate, the running time, the resolution and a thumbnail, before anything is fetched. It folds away when the field is empty, so the composer never moves.
  • The queue uses that picture too — the row shows the thumbnail and the estimated size while the download is still running, instead of a generic glyph and the word "requesting".
  • Cover art is a setting: embed the thumbnail in mp3, ogg and opus files, or leave the file clean. source and wav are never touched.
  • A download now shows itself: the queue opens on any screen, the bar fills with real percentages, speed and time left, and the badge pulses while work is running. It used to open only above 720px, so phones saw nothing until the file arrived.
  • Paste tells you what to do when the clipboard is blocked on iOS or Android, instead of naming a Mac shortcut.
  • iOS hands downloads to Safari's downloader — a blob opens in a viewer there and never reaches Files.
  • fetch is a full-width 48px target on phones, and the modes split the row evenly.
  • Fields are 16px on phones so iOS stops zooming the page when you tap them.
  • No accidental pull-to-refresh mid-download. No sideways scroll at 320px.
  • The status pill says online instead of a hostname, with the address in its tooltip.
  • The hero is a mark and a wordmark, mdown.cc, with the cc the same size as the name and a shade quieter so the wordmark still reads as a name.
  • A test taps every visible button on a 390px screen and fails if any of them throws.
  • The top bar is brand + tools on the left, the connection dot and the queue on the right, and nothing else. The connection pill means connection again — it opens the pane with the address, the health link and the status page — and the queue has its own small button.
  • The footer is terms · how it works; the help moved down there so the top bar has three things at most, and status lives inside the connection pill.
  • Inside a tool, the way back is ← download, and on a phone it collapses to just ← because the word cost 47px of top bar.
  • Arriving on the page puts the caret in the link field, with whatever is there selected, so typing replaces it. Returning to the tab does the same when nothing else has focus. (iOS still won't raise the keyboard without a tap — Safari's rule, not ours.)
  • Every dropdown — tools, sources, the queue — drops with the same 4px, 150ms motion on the same curve, and the panel it belongs to is the point it grows out of. One family instead of three implementations.
  • The mark drops into the tray on load and replays when you point at the name; the fetch button brightens on hover. Nothing animates inside the button itself — that version re-rasterised the whole control on every hover and felt slower than the one it replaced.
  • The sources list is pinned to the top centre of the screen rather than floating wherever the centred column put it, and it hangs off the count with a chevron that turns over.
  • The sources list is one flat alphabetical wrap of everything mdown accepts — 33 services, including imgur — plus anything the connected instance advertises that the list has not learned yet. No group headers, no encrypted services, 660px wide, and it leaves with the same short slide it arrives with.
  • Double-tap no longer zooms anything on a phone. Pinch still works — only the accidental gesture is gone.
  • A finished download says where it went: Files → Downloads on iOS, Downloads on Android, your downloads folder on a desktop. "Saved" on its own left you hunting.
  • The 404 page — the one every bare mdown.cc/link lands on — now carries a content security policy like every other page, and a narrower one than the app needs.
  • A rebuilt donate page: one card that says whether the tip jar is open, copy buttons that answer when you press them, and sharing treated as the real option instead of a footnote. It no longer quotes what the site costs to run — that is nobody's business but ours. Nothing on it loads from a third party.
  • An updates page (this one) and a one-line explanation at the top of every settings pane. "Output" is now "Files", because that's what it holds.
  • The active nav item stopped looking like a button — it names where you are now.
  • Sharing moved onto the donate page: copy the link, or post it straight to x, threads, reddit or bluesky. Each one is an ordinary link with no referrer, so nothing is requested until you press it.
1.2 13 nov 2026

It's live

  • mdown.cc served statically with a real certificate and HTTPS enforced; api.mdown.cc on the box, Let's Encrypt, renewing itself.
  • 8 parallel range requests per download instead of 4 — measured 39% faster on a 900 MB 4K file. 16 was slower on one core.
  • Output cap raised to 2 GB. The old 800 MB ceiling rejected a 966 MB 4K file, which meant the highest quality was advertised and then refused.
  • Range requests: a dropped connection on a big file resumes instead of starting over.
  • Files over 200 MB go straight to the browser. Buffering a gigabyte in the JS heap killed the tab.
  • A watchdog restarts the API when it's alive but wedged; a scheduled check opens an issue if the box stops answering.
  • A refused POST no longer poisons the connection — that showed up as "can't reach the API" on the second attempt.
1.1 12 nov 2026

Limits that tell the truth

  • Error messages name the actual problem: daily cap, burst limit, full queue, disk space, a missing API key.
  • The status page reports real uptime from the API's own checks.
  • A content security policy on every page, verified to allow the local ffmpeg engine and nothing else.
  • Donations dialog, off by default, that loads nothing from anywhere.
1.0 11 nov 2026

First release

  • One page: paste a link, pick a mode, get a file. No account, no build step.
  • Its own API: yt-dlp + ffmpeg, no Docker, no Node, caps on duration, height and size.
  • Remux, subtitle extraction and metadata cleaning run locally in your browser — those files never leave your device.
  • Pickers for playlists, subtitle embedding, silent video, and untouched source audio.

The code is open source under the MIT licence. Back to the downloader.
