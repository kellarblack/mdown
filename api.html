mdown.cc

API use

api.mdown.cc is one small server, run for this page. Not a public API.

what it is for

the mdown.cc page. that is the whole client. one person, at human speed.

what it is not

  • not a public API. there is no key, no quota and no contract.
  • not for other apps, bots, scrapers, resale, or "unlimited downloader" sites.
  • not an endpoint to be indexed, mirrored or pointed at in bulk.

limits, enforced

  • 2 downloads at once, 6 waiting.
  • 30 requests per minute, 60 downloads per 5 minutes, 500 jobs per day, per address.
  • 2 GB per file, 30 minutes, up to 8K.
  • requests from other origins are refused. a 429 means stop, not retry harder.

if you need an API

run your own. the code is MIT, the server is one Python process with yt-dlp and ffmpeg, and it runs on the smallest VPS you can buy. see the terms.

changes

these numbers can change without notice. blocking is automatic and permanent for repeat offenders.
